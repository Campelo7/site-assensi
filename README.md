# Assensi — Site institucional

Site para apresentação de uma clínica de estética, seus serviços, equipe e informações de contato.

[Acessar o site](https://site-assensi.vercel.app)

## Tecnologias

* HTML.
* CSS.
* JavaScript.
* Hospedagem na Vercel.

## Organização

* `index.html`: página principal.
* `assets/css/`: estilos e definições visuais.
* `assets/js/`: scripts da interface.
* `design-system.html`: referência visual do projeto.
* `robots.txt` e `sitemap.xml`: arquivos de apoio à indexação.

## Visualização local

Abra o arquivo `index.html` no navegador. Para trabalhar no projeto com atualização durante a edição, utilize um servidor local de arquivos estáticos.
